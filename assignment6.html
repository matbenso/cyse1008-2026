4) Create a Stripe account and get your API key

Each student needs their own free Stripe developer account. No business information or credit card is required — you will only ever use test mode.

  1. Go to stripe.com and click Sign in → Create account. Use your school email address.
  2. After signing up, Stripe may offer to create a sandbox. Accept this — a sandbox is a fully isolated test environment. If it does not offer one, that is fine; the default test mode works identically.
  3. Once you are in the Stripe dashboard, look at the top-right corner. Make sure the toggle shows Test mode (not Live mode). The toggle looks like a switch labelled "Test mode". If it is off, click it to turn it on. Your dashboard header should change colour to indicate you are in test mode.
  4. In the left sidebar, click Developers, then click API keys.
  5. You will see a Secret key that starts with sk_test_. Click Reveal test key to show the full value, then copy it.
  6. Open your .env.development file in the project root and add this line (paste your own key after the equals sign): 
    STRIPE_SECRET_KEY=sk_test_paste_your_key_here
    Save the file.

Note: .env.development is listed in .gitignore and will never be committed to Git. Your key stays on your machine only.

5) Set up Stripe webhooks with the VS Code extension

A webhook is how Stripe notifies your app that a payment completed. When running locally, Stripe cannot reach your machine directly — the Stripe VS Code extension solves this by forwarding webhook events from Stripe's servers to your local dev server in real time.

You will end up with two Stripe keys in your .env.development:

  • STRIPE_SECRET_KEY — copied from the Stripe dashboard (step 4 above). This authenticates your app with Stripe's API.
  • STRIPE_WEBHOOK_SECRET — generated locally when you start the webhook forwarder (this step). This lets your app verify that incoming webhook events really came from Stripe and not from someone else.

Install the extension:

  1. Open VS Code. Click the Extensions icon in the left sidebar (or press Ctrl+Shift+X).
  2. Search for Stripe and install the extension published by Stripe.
  3. After it installs you will see a new Stripe logo (looks like an S) appear in the left sidebar. Click it.
  4. The Stripe panel will open and ask you to sign in. Click Sign in with GitHub (or email) and follow the prompts in your browser. Return to VS Code once authorised.

Create the launch configuration file:

The project includes a .vscode/launch.json file that configures the webhook forwarder. If it is not present in your project (check by looking for a .vscode folder in the project root), create it now:

  1. In the project root, create a folder called .vscode if it does not exist.
  2. Inside that folder, create a file called launch.json with exactly this content: 
    {
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Stripe: Forward webhooks",
      "type": "stripe",
      "request": "launch",
      "command": "listen",
      "forwardTo": "http://localhost:3032/api/stripe/webhook"
    }
  ]
}
  3. Save the file.

Start the webhook forwarder:

  1. In VS Code, open the Run and Debug panel by pressing Ctrl+Shift+D (or clicking the play-with-bug icon in the left sidebar).
  2. At the top of the panel you will see a dropdown. Click it and select "Stripe: Forward webhooks" from the list.
  3. Click the green play button next to the dropdown.
  4. A terminal panel will open at the bottom of VS Code. After a few seconds you should see output that includes a line like: 
    > Ready! Your webhook signing secret is whsec_abc123...
    If you do not see this line, scroll up in the terminal — it appears near the top of the output when the forwarder starts. Your secret will be different from the example above.
  5. Copy the full whsec_... value.
  6. Open your .env.development file and add this line: 
    STRIPE_WEBHOOK_SECRET=whsec_paste_your_secret_here
    Save the file. Your .env.development should now have both keys: 
    STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
  7. Restart the dev server (npm run dev) so it picks up the new secret.

Important: The webhook secret changes every time you restart the forwarder. If you stop and restart it, copy the new secret into .env.development and restart the dev server again.

Troubleshooting:

  • If the extension says "Stripe CLI not found", the Stripe CLI needs to be installed. Run this in the terminal: 
    curl -s https://packages.stripe.dev/api/security/keypair/stripe-cli-gpg/public | gpg --dearmor | sudo tee /usr/share/keyrings/stripe.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/stripe.gpg] https://packages.stripe.dev/stripe-cli-debian-local stable main" | sudo tee /etc/apt/sources.list.d/stripe.list
sudo apt update && sudo apt install stripe
    Then restart VS Code and try again.
  • If the Run and Debug dropdown is empty or shows "No Configurations", the .vscode/launch.json file is missing — follow the "Create the launch configuration file" steps above.
  • If the forwarder starts but the terminal shows "Webhook signature verification failed", your STRIPE_WEBHOOK_SECRET in .env.development does not match the secret the forwarder printed. Copy it again and restart the dev server.

6) Start the app and emulators

You need both the dev server and the Firebase emulators running for this assignment.

In one terminal:

npm run dev

In a second terminal:

npm run dev:emulators

The web app runs on http://localhost:3032. The Firebase Emulator UI is at http://localhost:4000.
